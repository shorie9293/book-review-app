# 書見台（しょけんだい）— 読書を神遊びに変える書評アプリ

## 短い説明
蔵書を神域に記し、書評の星を灯せ。読書の歩みが冒険になる、和風RPG調の書評アプリ。

## 完全な説明

### ようこそ、書見台へ

ここは、あなたの読書を「神遊び」に変える聖域——書見台。
ISBNバーコードをかざせば、たちまち蔵書の帳に刻まれ、
読み終えた書には星の評価と想いを綴ることができる。

ただ本を管理するだけじゃない。
一冊一冊の書評が、あなただけの「知恵の書庫」を紡いでゆく。
積み重なる星の数が、読書の冒険の証となる。

### 主な特徴

- **📡 ISBNバーコードスキャン** — 本のバーコードをかざすだけ。瞬時に書名・著者を取得し、蔵書に追加
- **📚 蔵書の帳** — あなたの全蔵書を一望。読みたい本、読み終えた本、すべてここに
- **⭐ 五つ星の書評** — 星1〜5の評価と自由な感想文で、読み終えた想いを永遠に刻む
- **🔍 書籍検索** — タイトルでもISBNでも、読みたい本をすぐに見つけられる
- **✏️ 書評の編集** — 感想は変わってよい。いつでも書評を書き直し、星を付け替えられる
- **🎨 和のこころ** — 紺青と金色を基調とした、落ち着きある和風の画面設計
- **📴 オフライン完動** — 一度登録した蔵書と書評は、ネットがなくてもいつでも見返せる

### 書見台が選ばれる理由

書見台は「ただの蔵書管理アプリ」ではない。
一冊読むたびに星が灯り、感想が積み重なる——
それはまるで、RPGの冒険録のよう。

あなたの読書人生が、ここに一つの物語として紡がれてゆく。
